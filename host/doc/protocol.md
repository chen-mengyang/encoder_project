# UART 半双工单总线通讯协议

## 1. 概述

本协议用于主机与 **STM32G030F6P6 从机** 之间的单线半双工 UART 通讯。从机挂载：

- **MT6816** 磁编码器（SPI1, Mode3, 2MHz, PA1 软控 CS）
- **24C02** EEPROM（I2C1, 100kHz, PB8/PB9 上拉）— 保存从机地址
- **ADC** 电压采样（PA0）

从机默认地址为 `0x00`，同时 `0x00` 也是**广播地址**（所有从机响应）。

## 2. 物理层

| 参数 | 值 |
|------|-----|
| 接口 | USART1 半双工单线（PA9 TX / PA10 RX 短接） |
| 波特率 | 115200 |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验 | 无 |
| 模式 | 从机（收 → 回复 → 收） |

## 3. 帧格式

### 3.1 主机 → 从机（请求帧）

```
| AA | BB | ADDR | FUNC | LEN | DATA[0..LEN-1] | SUM |
```

| 字段 | 长度 | 说明 |
|------|------|------|
| `AA` | 1 | 帧头 0 |
| `BB` | 1 | 帧头 1 |
| `ADDR` | 1 | 目标地址（`0x00`=广播，`0x01~0xFF`=单播） |
| `FUNC` | 1 | 功能码（见 §4） |
| `LEN` | 1 | 数据区长度（0~60） |
| `DATA` | LEN | 数据区 |
| `SUM` | 1 | 校验和 |

### 3.2 从机 → 主机（应答帧）

```
| AA | BB | ADDR | RSP | LEN | DATA[0..LEN-1] | SUM |
```

| 字段 | 长度 | 说明 |
|------|------|------|
| `AA` | 1 | 帧头 0 |
| `BB` | 1 | 帧头 1 |
| `ADDR` | 1 | 从机自身地址 |
| `RSP` | 1 | 应答码（见 §5） |
| `LEN` | 1 | 数据区长度 |
| `DATA` | LEN | 数据区 |
| `SUM` | 1 | 校验和 |

### 3.3 校验和（SUM）

```
SUM = (ADDR + FUNC/RSP + LEN + ΣDATA) & 0xFF
```

即从 `ADDR` 到 `DATA` 末字节的累加和，取低 8 位。

## 4. 功能码（FUNC）

| 功能码 | 名称 | 模式 | 数据长度 | 说明 |
|--------|------|------|----------|------|
| `0x01` | CMD_READ_ANGLE | 单播 | 0 | 读 MT6816 角度 |
| `0x02` | CMD_READ_VOLT | 单播 | 0 | 读 ADC 电压（mV） |
| `0x03` | CMD_READ_STATUS | 单播 | 0 | 读状态字 |
| `0x04` | CMD_SET_ADDR | 广播 | 1 | 设置从机地址（DATA[0]=新地址） |
| `0x05` | CMD_GET_ADDR | 广播 | 0 | 获取从机地址 |

> **注意**：`CMD_SET_ADDR` 和 `CMD_GET_ADDR` 必须使用广播地址 `0x00`。

## 5. 应答码（RSP）

| 应答码 | 名称 | 数据长度 | 说明 |
|--------|------|----------|------|
| `0x81` | RSP_READ_ANGLE | 4 | 角度数据 |
| `0x82` | RSP_READ_VOLT | 2 | 电压（mV，大端） |
| `0x83` | RSP_READ_STATUS | 1 | 状态字 |
| `0x84` | RSP_SET_ADDR | 1 | 设置成功，回传新地址 |
| `0x85` | RSP_GET_ADDR | 1 | 从机地址 |

## 6. 命令详解

### 6.1 读角度（CMD_READ_ANGLE = 0x01）

**请求**（单播，ADDR=从机地址）：
```
AA BB [ADDR] 01 00 [SUM]
```

**应答**（RSP_READ_ANGLE = 0x81，4 字节数据）：
```
AA BB [ADDR] 81 04 [ANGLE_H] [ANGLE_L] [STATUS] [0x00] [SUM]
```

| 数据字节 | 说明 |
|----------|------|
| `ANGLE_H` | 角度高 6 位（bit5~bit0） |
| `ANGLE_L` | 角度低 8 位 |
| `STATUS` | MT6816 状态：bit0=奇校验位，bit1=No_Mag 警告 |
| `0x00` | 保留 |

**角度计算**：
```
angle = (ANGLE_H << 8) | ANGLE_L   // 14 位，0~16383
```

### 6.2 读电压（CMD_READ_VOLT = 0x02）

**请求**（单播）：
```
AA BB [ADDR] 02 00 [SUM]
```

**应答**（RSP_READ_VOLT = 0x82，2 字节数据）：
```
AA BB [ADDR] 82 02 [VOLT_H] [VOLT_L] [SUM]
```

**电压计算**（大端）：
```
voltage_mV = (VOLT_H << 8) | VOLT_L
```

### 6.3 读状态字（CMD_READ_STATUS = 0x03）

**请求**（单播）：
```
AA BB [ADDR] 03 00 [SUM]
```

**应答**（RSP_READ_STATUS = 0x83，1 字节数据）：
```
AA BB [ADDR] 83 01 [STATUS] [SUM]
```

**状态字位定义**：

| bit | 名称 | 说明 |
|-----|------|------|
| bit0 | STATUS_ADDR_UNSET | 地址未配置（当前为默认 0x00） |
| bit1 | STATUS_MAG_ERR | MT6816 无磁场/校验错误 |
| bit2 | STATUS_EEPROM_ERR | 24C02 EEPROM 通信失败（器件不在线） |

### 6.4 设置地址（CMD_SET_ADDR = 0x04）

**请求**（广播，ADDR=0x00，1 字节数据）：
```
AA BB 00 04 01 [NEW_ADDR] [SUM]
```

| 数据字节 | 说明 |
|----------|------|
| `NEW_ADDR` | 新从机地址（`0x01~0xFF`，不可为 `0x00`） |

**应答**（RSP_SET_ADDR = 0x84，1 字节数据）：
```
AA BB [NEW_ADDR] 84 01 [NEW_ADDR] [SUM]
```

> 设置成功后写入 24C02 EEPROM 首字节，掉电不丢失，并立即生效。

### 6.5 获取地址（CMD_GET_ADDR = 0x05）

**请求**（广播，ADDR=0x00）：
```
AA BB 00 05 00 [SUM]
```

**应答**（RSP_GET_ADDR = 0x85，1 字节数据）：
```
AA BB [ADDR] 85 01 [ADDR] [SUM]
```

> 所有从机都会回应自己的地址。主机可通过过滤 `ADDR != 0x00` 的应答帧来枚举总线上的从机。

## 7. 地址规则

| 地址 | 含义 |
|------|------|
| `0x00` | 广播地址（所有从机响应），同时是出厂默认地址 |
| `0x01 ~ 0xFF` | 单播地址（仅匹配的从机响应） |

- 从机地址保存在 24C02 EEPROM 首字节（offset 0x00）
- 上电时自动读取，无效则使用默认 `0x00`
- 通过 `CMD_SET_ADDR` 广播设置，写入 EEPROM 并立即生效

## 8. 串口助手测试指令（16 进制）

假设从机地址为 `0x01`：

| 操作 | 发送帧 | 说明 |
|------|--------|------|
| 读角度 | `AA BB 01 01 00 02` | SUM = 01+01+00 = 02 |
| 读电压 | `AA BB 01 02 00 03` | SUM = 01+02+00 = 03 |
| 读状态 | `AA BB 01 03 00 04` | SUM = 01+03+00 = 04 |
| 设置地址为 0x21 | `AA BB 00 04 01 21 26` | SUM = 00+04+01+21 = 26 |
| 获取地址 | `AA BB 00 05 00 05` | SUM = 00+05+00 = 05 |

> 校验和需按 `SUM = (ADDR + FUNC + LEN + ΣDATA) & 0xFF` 计算，上表为示例值，请以实际计算为准。

## 9. 硬件接口

| 外设 | 接口 | 引脚 | 配置 |
|------|------|------|------|
| USART1 | 半双工单线 | PA9 (TX) / PA10 (RX) | 19200-8-N-1 |
| MT6816 | SPI1 | PA5 (SCK) / PA6 (MISO) / PA7 (MOSI) / PA1 (CS) | Mode3, 2MHz |
| 24C02 | I2C1 | PB8 (SCL) / PB9 (SDA) | 100kHz, 上拉 |
| ADC | ADC1 | PA0 | 电压采样 |
| LED | TIM1 CH3 | PA10 | PWM 呼吸/闪烁 |
